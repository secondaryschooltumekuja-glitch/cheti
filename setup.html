Database Setup and Configuration

📋 Setup Instructions:

  1. Start XAMPP Control Panel
  2. Start Apache service (click "Start" next to Apache)
  3. Start MySQL service (click "Start" next to MySQL)
  4. Wait for both services to show "Running" status
  5. Click "Check MySQL Status" to verify MySQL is working
  6. Click "Setup Database" to create the database and tables
  7. Click "Test Database Connection" to verify everything works
  8. Go to Certificate System to start using the application

🛠️ Database Details:

  • Database Name: tumekuja_certificates
  • Server: localhost
  • Username: root
  • Password: (empty)
  • Port: 3306

🚨 MySQL Not Working? Try These Steps:

  1. Install XAMPP: Download from apachefriends.org
  2. Run as Administrator: Right-click XAMPP Control Panel → "Run as administrator"
  3. Start Services: Click "Start" next to Apache and MySQL
  4. Check Ports: Make sure port 3306 (MySQL) is not used by other programs
  5. Windows Users: Disable Windows MySQL service if installed
  6. Firewall: Allow XAMPP through Windows Firewall
